# Atribuições

O +Mangue utiliza os seguintes recursos de terceiros:

- **Imagens do hero** — fotos do [Unsplash](https://unsplash.com), usadas sob a
  [licença do Unsplash](https://unsplash.com/license).
- **Mapa interativo** — biblioteca [Leaflet](https://leafletjs.com/) com tiles do
  [CARTO](https://carto.com/) e dados do
  [© OpenStreetMap contributors](https://www.openstreetmap.org/copyright) (ODbL).
- **Tipografia** — fontes [Lora](https://fonts.google.com/specimen/Lora) e
  [Work Sans](https://fonts.google.com/specimen/Work+Sans) via Google Fonts (Open Font License).
- **Ícones** — [Lucide](https://lucide.dev/) (ISC License).
- **Notificações** — [Sonner](https://sonner.emilkowal.ski/) (MIT License).
- **Carrossel** — [react-slick](https://react-slick.neostack.com/) / slick-carousel (MIT License).
